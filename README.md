# Ohtla Portable Base

A Cloudflare-first foundation for open-source applications that small businesses can run in their own accounts.

## Purpose

This repository will provide a repeatable path for local development, deployment, data migration, backup, and recovery. Business rules should remain independent of Cloudflare bindings so each application can adopt only the services it needs.

Portability does not mean that every provider is supported. Each application must document and test the deployment profiles it actually offers, and provide a usable way to export its data.

## Status

The project is in its initial setup stage. It does not yet contain a deployable application or validated alternative runtime.
